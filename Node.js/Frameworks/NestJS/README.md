# Core Purpose
| Aspect                | **Next.js**                   | **NestJS**            |
| --------------------- | ----------------------------- | --------------------- |
| Primary role          | Web application framework     | Backend API framework |
| Category              | Frontend (Full-stack capable) | Backend only          |
| UI rendering          | ✅ Yes (React)                 | ❌ No                  |
| REST / GraphQL APIs   | ⚠️ Limited (API routes)       | ✅ Full-featured       |
| Server-side rendering | ✅ Core feature                | ❌ Not applicable      |
