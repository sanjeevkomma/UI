* React Native → Cross-platform framework (Android + iOS, one codebase)
# React Native vs Kotlin
| Feature           | React Native      | Kotlin                    |
| ----------------- | ----------------- | ------------------------- |
| Type              | Framework         | Language (native Android) |
| Platform          | Android + iOS     | Android only              |
| Language          | JavaScript        | Kotlin (Java-based)       |
| Performance       | Medium            | 🔥 High                   |
| Development Speed | 🔥 Fast           | Medium                    |
| UI Control        | Limited sometimes | Full control              |
| Learning Curve    | Easy–Medium       | Easy (for Java devs)      |

# When to Choose React Native
* Pick React Native if you want:
    * One app for Android + iOS
    * Faster development
    * Startup / MVP building
    * Quick side projects
